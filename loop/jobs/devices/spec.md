# 全ツールを Chromebook・Windows・iPad で同じように使えるようにする

## 目的（おかだ先生より）
Chromebook、Windows、iPad で操作したときに、どのツールも同じように動くこと。

## 3つの端末（tests/smoke.cjs の --device）
| 名前 | 画面（ページが使える広さ） | 操作 |
|---|---|---|
| chromebook | 1366×650、拡大1倍 | マウスと指（タブレットにできる機種が多い） |
| windows | 1536×730（1920×1080 の125%）、拡大1.25倍 | マウス |
| ipad | 1180×740、拡大2倍、Safari（Mac と名乗り、指が使える） | 指とペン |

このクラウドには Chromium しかないので、ipad は「大きさと指」だけのまねです。Safari だけのちがいは `tests/ipad-pitfalls.mjs` がコードから探します。

## 合格
- `node tests/smoke.cjs --device=<端末> <ツール>` が通る（横にはみ出さない検査も入っている）。
- `node tests/ipad-pitfalls.mjs <フォルダ>` が通る。
- ほかの端末・ふつうの `node tests/smoke.cjs <ツール>` も壊さない。

## 直し方の決まり
- 直すのはツール（アプリ）のほう。テストが間違っていると思ったら、直さずに progress.md に理由を書く。
- 端末によって機能を減らさない。Chromebook でできることは残し、iPad にはそれに代わるやり方を足す。
- 100vh は `100vh` の次の行に `100dvh` を足す（古い端末のため 100vh は残す）。
- ダブルクリックだけでできる操作は、同じことができるボタンなどを足す。すでにあるなら、その行に `// ipad-ok: <そのボタンの名前>` と書いてよい。
- 見た目はなるべく変えない。直した理由は、ふつうの言葉でコードのコメントに1行。
