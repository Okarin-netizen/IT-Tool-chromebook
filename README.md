# IT-Tool-chromebook

学校のChromebookで、インストールなし・ブラウザだけで使える便利ツール集です。
GitHub Pages で公開して使います。

## ツール一覧

| フォルダ | ツール | 内容 |
| --- | --- | --- |
| [`pdf-text/`](pdf-text/) | PDF文字入れ | PDFに日本語の文字や写真を書き込み、新しいPDFとしてダウンロード |
| [`pdf-pages/`](pdf-pages/) | PDF結合・分割・回転 | 複数のPDFを結合、ページの抜き出し・1ページずつ分割、並べ替え、回転 |
| [`image-pdf/`](image-pdf/) | 画像→PDF | 写真や画像を並べ替えて1つのPDFにまとめてダウンロード |
| [`pdf-compress/`](pdf-compress/) | PDF圧縮 | PDFの中の画像を縮小・再圧縮してファイルサイズを小さくする（目標サイズ指定も可） |
| [`pdf-image/`](pdf-image/) | PDF→画像 | PDFのページをPNG / JPGの画像にして保存（複数ページはZIP）、コピーして貼り付け |
| [`calc/`](calc/) | 関数電卓・グラフ | 三角関数・対数などの計算と、関数のグラフ描画 |
| [`todo/`](todo/) | 時間割・課題チェックリスト | 時間割と課題をブラウザに保存して管理 |
| [`timer/`](timer/) | タイマー・ポモドーロ | 勉強時間を計るポモドーロ、カウントダウンタイマー、ストップウォッチ |
| [`image-annotate/`](image-annotate/) | 画像に書き込み | スクリーンショットや写真に矢印・文字・図形・モザイクを書き込み、PNGで保存 |

トップページ（`index.html`）が共通の入り口で、ここから各ツールを選べます。PDF関係のツール（PDF文字入れ・PDF結合・分割・回転・画像→PDF・PDF圧縮）は「📄 PDF」としてまとめて横に並べています。

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://okarin-netizen.github.io/IT-Tool-chromebook/` で開けます

一度開くとブラウザにキャッシュされ、各ツールはオフラインでも動きます。

## ツールの追加方法

1. ルートに新しいフォルダ（例: `timer/`）を作り、`index.html` を置く
2. ルートの `index.html` で、合うグループ（「📄 PDF」か「🧰 そのほかのツール」）の `<ul class="tools">` に `<li>` を1つ追加する
3. この README の表に1行追加する

ビルド作業は不要です。外部ライブラリは CDN を使わずフォルダ内に同梱します（学校のネットワークで CDN がブロックされることがあるため）。

## PDF文字入れ

- PDFを開いて、文字を入れたい場所をクリックして入力
- 文字サイズ・色（黒/赤/青/緑）を変更可能、複数行OK
- 「✥」をドラッグして移動、「✕」で削除
- 「🖼 写真を追加」で写真・画像を貼り付け（ドラッグで移動、右下の角で拡大縮小）。大きな写真は自動で縮小されます
- 「💾 PDFを保存」で `元の名前_記入済み.pdf` をダウンロード
- 編集が制限された（保護付き）PDFも保存可能。この場合は元のページを画像にしてから書き込むため、元の文字は選択・検索できなくなります
- PDFはどこにも送信されず、ブラウザ内で処理されます

## 画像→PDF

- 「🖼 画像を追加」またはドラッグ＆ドロップで写真・画像を何枚でも追加（Ctrl+V でスクリーンショットの貼り付けもOK）
- 「📷 カメラで撮る」でChromebookのカメラから直接撮影して追加
- 画像をドラッグするか「◀ ▶」で並べ替え、「⟳」で90°回転、「✕」で削除、「↕ 名前順」でファイル名順に整列
- 用紙（A4 / B5 / レター / 画像に合わせる）、向き（自動 / 縦 / 横）、余白、色（カラー / 白黒）を選べます
- 「💾 PDFを保存」で1枚1ページのPDFをダウンロード。大きな写真は自動で縮小されます
- iPhoneのHEIC形式はブラウザが読めないため、JPEGで撮影・保存したものを使ってください
- 画像はどこにも送信されず、ブラウザ内で処理されます

## 関数電卓・グラフ

- 「🧮 電卓」: sin・cos・tan（と逆関数）、ln・log、√、累乗、階乗、π、e、前の答え（Ans）が使えます
- 角度は DEG（度）/ RAD（ラジアン）を切りかえ可能。`2π`・`3(1+2)` のようなかけ算記号の省略もOK
- キーボードでも入力でき、Enter で計算、Esc で消去。計算の履歴は押すと呼び出せます
- 「📈 グラフ」: `y = x^2-2x-3` のように式を入れると、最大8本まで色分けして描きます（角度はラジアン）
- ドラッグで移動、ホイールやピンチで拡大縮小、カーソルを近づけるとグラフ上の座標を表示
- 式・履歴・設定はこのブラウザに保存されます。外部ライブラリなし、オフラインでも動きます

## 時間割・課題チェックリスト

- 時間割のマスをクリックして科目を入力（4〜8時間、土曜の表示切り替えOK）。今日の曜日に色が付きます
- 課題は内容・科目・締め切りを入れて追加。締め切りが近い順に並び、過ぎたものは赤、今日・明日のものはオレンジで表示
- チェックで完了、「完了した課題を消す」でまとめて削除
- データはブラウザ（localStorage）に自動保存。「⬇ バックアップ」でファイルに保存、「⬆ 読み込み」で復元できます

## タイマー・ポモドーロ

- **🍅 ポモドーロ**: 集中25分 → 休憩5分をくり返し、4回ごとに長い休憩15分（時間と回数は「⚙ 時間の設定」で変更可能）。今日の集中回数と分数を記録
- **⏳ タイマー**: 1〜60分のボタン、または分・秒を入力してカウントダウン。テスト練習に
- **⏱ ストップウォッチ**: 0.1秒単位、ラップ記録つき
- 時間になると音（オフにも可）と、別のタブを見ているときは通知でお知らせ
- 「⛶」で全画面表示。動いている間は画面が暗くならないようにします
- ページを閉じたり再読み込みしても、続きから表示されます
- キーボード: スペース=スタート/一時停止、R=リセット、F=全画面、L=ラップ

## 画像に書き込み

- 「📂 画像を開く」、ドラッグ＆ドロップ、または <kbd>Ctrl</kbd>+<kbd>V</kbd>（スクリーンショットの貼り付け）で画像を開く。白紙から描くこともできます
- 道具: 矢印・文字・四角・丸・直線・ペン・蛍光ペン・モザイク（名前など見せたくない所をぼかす）
- 色6色・太さ4段階・四角と丸の塗りつぶし。<kbd>Shift</kbd> を押しながら描くと、線は45°ごと、四角と丸は正方形・正円になります
- 「👆 選択」で描いたものをドラッグして移動、端の丸いつまみで形を変更。文字はダブルクリックで書き直し。選んだまま色や太さを押すと変更できます
- 元に戻す/やり直す（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>）、<kbd>Delete</kbd> で削除
- 「💾 保存」で `元の名前_書き込み.png` をダウンロード、「📋 コピー」でドキュメントやスライドに貼り付け
- 外部ライブラリは使っていません。画像はどこにも送信されず、ブラウザ内で処理されます

## PDF結合・分割・回転

- 「📂 PDFを追加」またはドラッグで、PDFをいくつでも追加（全ページがサムネイルで並びます）
- ページをドラッグ、または「◀ ▶」で並べ替え（<kbd>Alt</kbd>+<kbd>←</kbd>/<kbd>→</kbd> でも移動）。タッチ画面ではページを長押ししてからドラッグ。「✕」でそのページを外す
- ページをクリックで選択（Shift+クリックで範囲選択、Ctrl+Aで全選択、Escで解除）。選んだページをドラッグすると、まとめて移動します
- 「🔍」またはダブルクリックでページを大きく表示。←/→ でページ送り、その場で回転・削除もできます
- 移動・回転・削除・追加は「↶ 元に戻す」「↷ やり直す」（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>）で取り消し・やり直しできます
- 「大きさ」でサムネイルを小・中・大に切り替え
- 「⟲ 左に回転」「⟳ 右に回転」は選んだページ（選んでいなければ全ページ）を90°回転
- 「💾 1つのPDFに保存」で並んでいる順に結合、「📄 選んだページを保存」で抜き出し、「✂ 1ページずつ保存」でページごとに分割
- 保護（編集制限）がかかったPDFも使えます。その場合、保存するときにページを画像にして取り込みます（文字の選択はできなくなります）。開くのにパスワードが必要なPDFは使えません
- 同梱ライブラリは pdf.js 4.10.38（表示）と pdf-lib 1.17.1（結合・回転）。PDF文字入れと同じものを `pdf-pages/lib/` にも入れています

## PDF圧縮

- 「📂 PDFを開く」またはドラッグでPDFを開き、圧縮のしかたと強さを選んで「🗜 圧縮する」
- **画像だけ軽くする（おすすめ）**: PDFの中の写真・スキャン画像を縮小してJPEGで保存し直します。文字はそのままなので選択・検索もできます
- **ページ全体を画像にする（強力）**: 各ページを画像にしてPDFを作り直します。どんなPDFでも小さくしやすい代わりに、文字の選択・検索はできなくなります
- 強さは「弱め（きれい）・標準・強め（小さい）」の3段階。「サイズ指定」で「2 MB 以下」のように目標を入れると、きれいな設定から順に試して目標に収まるものを選びます
- 圧縮前後のサイズと、仕上がりのページを確認してから「💾 保存」で `元の名前_圧縮.pdf` をダウンロード。小さくならなかったときは保存せず、元のファイルを使うよう案内します
- 文字だけのPDFはもともと軽いので、あまり小さくなりません
- 保護（編集制限）がかかったPDFは「ページ全体を画像にする」で圧縮します。開くのにパスワードが必要なPDFは使えません
- 同梱ライブラリは pdf.js 4.10.38（表示・ページの画像化）と pdf-lib 1.17.1（PDFの書き換え）。PDF結合・分割・回転と同じものを `pdf-compress/lib/` にも入れています

## PDF→画像

- 「📂 PDFを開く」またはドラッグでPDFを開くと、全ページがサムネイルで並びます
- 形式は PNG（文字がくっきり）か JPG（ファイルが軽い）、画質は 96 / 150 / 300 dpi から選べます（選んだ設定は次回も使われます）
- ページの「💾」でそのページを画像で保存、「📋」でコピーしてスライドやドキュメントに <kbd>Ctrl</kbd>+<kbd>V</kbd> で貼り付け
- ページをクリックで選択（Shift+クリックで範囲選択、Ctrl+Aで全選択、Escで解除）し、「💾 画像で保存」でまとめて保存。何も選ばなければ全ページ。2枚以上のときは `元の名前_画像.zip` にまとめます
- 保護（編集制限）がかかったPDFも使えます。開くのにパスワードが必要なPDFは、パスワードを入れると開けます
- 同梱ライブラリは pdf.js 4.10.38（表示・画像化）。`pdf-image/lib/` に入れています。ZIP作成は自前の小さなコード（`zip.js`）です
