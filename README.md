# IT-Tool-chromebook

学校のChromebookで、インストールなし・ブラウザだけで使える便利ツール集です。
GitHub Pages で公開して使います。

## ツール一覧

| フォルダ | ツール | 内容 |
| --- | --- | --- |
| [`pdf-text/`](pdf-text/) | PDF文字入れ | PDFに日本語の文字や写真を書き込み、新しいPDFとしてダウンロード |
| [`pdf-pages/`](pdf-pages/) | PDF結合・分割・回転 | 複数のPDFを結合、ページの抜き出し・1ページずつ分割、並べ替え、回転 |
| [`pdf-sign/`](pdf-sign/) | PDFに手書き・署名 | PDFにペン・蛍光ペンで書き込み、名前の印鑑や「済」「✓」などのハンコ、手書きの署名を入れて保存 |
| [`pdf-grade/`](pdf-grade/) | PDF一括採点 | 提出された複数のPDF（ZIP・フォルダも可）をまとめて開いて採点し、1人ずつ `_採点済.pdf` にしてZIPで保存。点数一覧CSVつき |
| [`image-pdf/`](image-pdf/) | 画像→PDF | 写真や画像を並べ替えて1つのPDFにまとめてダウンロード |
| [`pdf-compress/`](pdf-compress/) | PDF圧縮 | PDFの中の画像を縮小・再圧縮してファイルサイズを小さくする（目標サイズ指定も可） |
| [`pdf-image/`](pdf-image/) | PDF→画像 | PDFのページをPNG / JPGの画像にして保存（複数ページはZIP）、コピーして貼り付け |
| [`pdf-stamp/`](pdf-stamp/) | ページ番号・透かし入れ | PDFの全ページにページ番号や「下書き」などの透かしを一括で入れる |
| [`pdf-extract/`](pdf-extract/) | PDF文字取り出し | PDFの文字を取り出してコピー・テキスト保存。スキャンしたPDFはOCRで読み取り |
| [`calc/`](calc/) | 関数電卓・グラフ | 三角関数・対数などの計算と、関数のグラフ描画 |
| [`todo/`](todo/) | 時間割・課題チェックリスト | 時間割と課題をブラウザに保存して管理 |
| [`timer/`](timer/) | タイマー・ポモドーロ | 勉強時間を計るポモドーロ、カウントダウンタイマー、ストップウォッチ |
| [`image-annotate/`](image-annotate/) | 画像に書き込み | スクリーンショットや写真に矢印・文字・図形・モザイクを書き込み、PNGで保存 |

トップページ（`index.html`）が共通の入り口で、ここから各ツールを選べます。PDF関係のツール（PDF文字入れ・PDF結合・分割・回転・画像→PDF・PDF圧縮・ページ番号・透かし入れ・PDF文字取り出し・PDFに手書き・署名・PDF一括採点）は「PDF」グループにまとめて横に並べています。

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://okarin-netizen.github.io/IT-Tool-chromebook/` で開けます

一度開くとブラウザにキャッシュされ、トップページと開いたことのあるツールはオフラインでも動きます。

## ツールの追加方法

1. ルートに新しいフォルダ（例: `timer/`）を作り、`index.html` を置く
2. ルートの `index.html` で、合うグループ（「PDF」か「そのほかのツール」）の `<ul class="apps">` に `<li>` を1つ追加する
3. この README の表に1行追加する

ビルド作業は不要です。外部ライブラリは CDN を使わず、`shared/vendor/` に1つだけ同梱して全ツールで共有します（学校のネットワークで CDN がブロックされることがあるため）。版・入手元・ライセンスの一覧は [`shared/vendor/README.md`](shared/vendor/README.md) にあります。

オフライン対応は、サイト全体で1つのサービスワーカー（ルートの `sw.js`）が受け持ちます。新しいツールでは、`app.js` の最後で `registerOffline([...])`（`shared/js/offline.js`）を呼び、そのツールのファイルの一覧を渡します。各ツールのフォルダにある `sw.js` は、古い版のサービスワーカーを外すためだけのもので、2027年2月以降に削除できます。

どのツールでも使う部品は `shared/` にまとめています。新しいツールもこれを使ってください。

- `shared/css/base.css`: 上のバー・ボタン・アイコン・メッセージなどの共通の見た目（各ツールの `style.css` より先に読み込む）
- `shared/js/status.js`: 画面下のメッセージ（`showStatus` / `hideStatus`）
- `shared/js/files.js`: ファイルの保存（`download`）とドラッグ&ドロップ（`onFileDrop`）
- `shared/js/storage.js`: 設定の保存（`loadJson` / `saveJson` など。保存できない環境でも止まらない）
- `shared/js/pdf.js`: pdf.js の準備（`openPdf`）と、保護されたPDFを画像にして作り直す処理（`rasterizePdf`）
- `shared/js/font-jp.js`: PDFに書き込む日本語フォントの準備（`subsetFont`）
- `shared/js/zip.js` / `unzip.js`: ZIPの作成と読み取り

## PDF文字入れ

- PDFを開いて、文字を入れたい場所をクリックして入力
- 文字サイズ・色（黒/赤/青/緑）を変更可能、複数行OK
- 「✥」をドラッグして移動、「✕」で削除
- 「写真を追加」で写真・画像を貼り付け（ドラッグで移動、右下の角で拡大縮小）。大きな写真は自動で縮小されます
- 「PDFを保存」で `元の名前_記入済み.pdf` をダウンロード
- 編集が制限された（保護付き）PDFも保存可能。この場合は元のページを画像にしてから書き込むため、元の文字は選択・検索できなくなります
- PDFはどこにも送信されず、ブラウザ内で処理されます

## 画像→PDF

- 「画像を追加」またはドラッグ＆ドロップで写真・画像を何枚でも追加（Ctrl+V でスクリーンショットの貼り付けもOK）
- 「カメラで撮る」でChromebookのカメラから直接撮影して追加
- 画像をドラッグするか「◀ ▶」で並べ替え、「⟳」で90°回転、「✕」で削除、「名前順」でファイル名順に整列
- 用紙（A4 / B5 / レター / 画像に合わせる）、向き（自動 / 縦 / 横）、余白、色（カラー / 白黒）を選べます
- 「PDFを保存」で1枚1ページのPDFをダウンロード。大きな写真は自動で縮小されます
- iPhoneのHEIC形式はブラウザが読めないため、JPEGで撮影・保存したものを使ってください
- 画像はどこにも送信されず、ブラウザ内で処理されます

## 関数電卓・グラフ

- 「電卓」: sin・cos・tan（と逆関数）、ln・log、√、累乗、階乗、π、e、前の答え（Ans）が使えます
- 角度は DEG（度）/ RAD（ラジアン）を切りかえ可能。`2π`・`3(1+2)` のようなかけ算記号の省略もOK
- キーボードでも入力でき、Enter で計算、Esc で消去。計算の履歴は押すと呼び出せます
- 「グラフ」: `y = x^2-2x-3` のように式を入れると、最大8本まで色分けして描きます（角度はラジアン）
- ドラッグで移動、ホイールやピンチで拡大縮小、カーソルを近づけるとグラフ上の座標を表示
- 式・履歴・設定はこのブラウザに保存されます。外部ライブラリなし、オフラインでも動きます

## 時間割・課題チェックリスト

- 時間割のマスをクリックして科目を入力（4〜8時間、土曜の表示切り替えOK）。今日の曜日に色が付きます
- 課題は内容・科目・締め切りを入れて追加。締め切りが近い順に並び、過ぎたものは赤、今日・明日のものはオレンジで表示
- チェックで完了、「完了した課題を消す」でまとめて削除
- データはブラウザ（localStorage）に自動保存。「バックアップ」でファイルに保存、「読み込み」で復元できます

## タイマー・ポモドーロ

- **🍅 ポモドーロ**: 集中25分 → 休憩5分をくり返し、4回ごとに長い休憩15分（時間と回数は「時間の設定」で変更可能）。今日の集中回数と分数を記録
- **⏳ タイマー**: 1〜60分のボタン、または分・秒を入力してカウントダウン。テスト練習に
- **⏱ ストップウォッチ**: 0.1秒単位、ラップ記録つき
- 時間になると音（オフにも可）と、別のタブを見ているときは通知でお知らせ
- 「全画面表示」ボタン（または <kbd>F</kbd> キー）で全画面表示。動いている間は画面が暗くならないようにします
- ページを閉じたり再読み込みしても、続きから表示されます
- キーボード: スペース=スタート/一時停止、R=リセット、F=全画面、L=ラップ

## 画像に書き込み

- 「画像を開く」、ドラッグ＆ドロップ、または <kbd>Ctrl</kbd>+<kbd>V</kbd>（スクリーンショットの貼り付け）で画像を開く。白紙から描くこともできます
- 道具: 矢印・文字・四角・丸・直線・ペン・蛍光ペン・モザイク（名前など見せたくない所をぼかす）
- 色6色・太さ4段階・四角と丸の塗りつぶし。<kbd>Shift</kbd> を押しながら描くと、線は45°ごと、四角と丸は正方形・正円になります
- 「選択」で描いたものをドラッグして移動、端の丸いつまみで形を変更。文字はダブルクリックで書き直し。選んだまま色や太さを押すと変更できます
- 元に戻す/やり直す（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>）、<kbd>Delete</kbd> で削除
- 「保存」で `元の名前_書き込み.png` をダウンロード、「コピー」でドキュメントやスライドに貼り付け
- 外部ライブラリは使っていません。画像はどこにも送信されず、ブラウザ内で処理されます

## PDF結合・分割・回転

- 「PDFを追加」またはドラッグで、PDFをいくつでも追加（全ページがサムネイルで並びます）
- ページをドラッグ、または「◀ ▶」で並べ替え（<kbd>Alt</kbd>+<kbd>←</kbd>/<kbd>→</kbd> でも移動）。タッチ画面ではページを長押ししてからドラッグ。「✕」でそのページを外す
- ページをクリックで選択（Shift+クリックで範囲選択、Ctrl+Aで全選択、Escで解除）。選んだページをドラッグすると、まとめて移動します
- 「大きく表示」ボタンまたはダブルクリックでページを大きく表示。←/→ でページ送り、その場で回転・削除もできます
- 移動・回転・削除・追加は「元に戻す」「やり直す」（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>）で取り消し・やり直しできます
- 「大きさ」でサムネイルを小・中・大に切り替え
- 「⟲ 左に回転」「⟳ 右に回転」は選んだページ（選んでいなければ全ページ）を90°回転
- 「1つのPDFに保存」で並んでいる順に結合、「選んだページを保存」で抜き出し、「1ページずつ保存」でページごとに分割
- 保護（編集制限）がかかったPDFも使えます。その場合、保存するときにページを画像にして取り込みます（文字の選択はできなくなります）。開くのにパスワードが必要なPDFは使えません
- 同梱ライブラリは pdf.js 4.10.38（表示）と pdf-lib 1.17.1（結合・回転）

## PDF圧縮

- 「PDFを開く」またはドラッグでPDFを開き、圧縮のしかたと強さを選んで「圧縮する」
- **画像だけ軽くする（おすすめ）**: PDFの中の写真・スキャン画像を縮小してJPEGで保存し直します。文字はそのままなので選択・検索もできます
- **ページ全体を画像にする（強力）**: 各ページを画像にしてPDFを作り直します。どんなPDFでも小さくしやすい代わりに、文字の選択・検索はできなくなります
- 強さは「弱め（きれい）・標準・強め（小さい）」の3段階。「サイズ指定」で「2 MB 以下」のように目標を入れると、きれいな設定から順に試して目標に収まるものを選びます
- 圧縮前後のサイズと、仕上がりのページを確認してから「保存」で `元の名前_圧縮.pdf` をダウンロード。小さくならなかったときは保存せず、元のファイルを使うよう案内します
- 文字だけのPDFはもともと軽いので、あまり小さくなりません
- 保護（編集制限）がかかったPDFは「ページ全体を画像にする」で圧縮します。開くのにパスワードが必要なPDFは使えません
- 同梱ライブラリは pdf.js 4.10.38（表示・ページの画像化）と pdf-lib 1.17.1（PDFの書き換え）

## PDF→画像

- 「PDFを開く」またはドラッグでPDFを開くと、全ページがサムネイルで並びます
- 形式は PNG（文字がくっきり）か JPG（ファイルが軽い）、画質は 96 / 150 / 300 dpi から選べます（選んだ設定は次回も使われます）
- ページの「このページを画像で保存」でそのページを画像で保存、「このページをコピー」でコピーしてスライドやドキュメントに <kbd>Ctrl</kbd>+<kbd>V</kbd> で貼り付け
- ページをクリックで選択（Shift+クリックで範囲選択、Ctrl+Aで全選択、Escで解除）し、「画像で保存」でまとめて保存。何も選ばなければ全ページ。2枚以上のときは `元の名前_画像.zip` にまとめます
- 保護（編集制限）がかかったPDFも使えます。開くのにパスワードが必要なPDFは、パスワードを入れると開けます
- 同梱ライブラリは pdf.js 4.10.38（表示・画像化）。ZIP作成は自前の小さなコード（`shared/js/zip.js`）です

## ページ番号・透かし入れ

- 「PDFを開く」またはドラッグでPDFを開くと、全ページの仕上がりが右側に表示されます（設定を変えるとすぐ反映）
- **ページ番号**: 形式（`1`・`- 1 -`・`1 / 10`・`p. 1`・`1ページ`）、位置（上下 × 左・中央・右）、大きさ・色・端からの距離、最初の番号を選べます
- 「自分で入力…」では `名前　{n} / {total}` のように、名前や科目も一緒に入れられます（`{n}` がページ番号、`{total}` が全ページ数）
- 「1ページ目（表紙）には入れない」をオンにすると、2ページ目から番号が始まります
- **透かし**: 「下書き」「見本」「コピー」などの文字を、斜め・横、中央に1つ・ページ全体に並べる、から選んで薄く入れます。大きさ・色・濃さも調整できます
- 「PDFを保存」で `元の名前_番号入り.pdf`（透かしだけなら `_透かし入り`、両方なら `_番号・透かし入り`）をダウンロード
- 保護（編集制限）がかかったPDFも使えます。その場合、元のページは画像になります（文字の選択はできなくなります）
- 設定はこのブラウザに保存され、次に開いたときも同じ設定で始まります。PDFはどこにも送信されません
- 同梱ライブラリはPDF文字入れと同じもの（pdf.js・pdf-lib・fontkit・harfbuzzjs・Noto Sans JP）です

## PDF文字取り出し

- 「PDFを開く」またはドラッグでPDFを開くと、ページごとに取り出した文字が並びます（左にページの画像）
- 「コピー」でそのページ、「全部コピー」で全ページをコピー。「テキストで保存」で `元の名前.txt` をダウンロード
- 「改行をつなげる」をオンにすると、PDFの行の途中で切れている改行をつなげて段落ごとの文章にします（見出しや箇条書きは別の行のまま）
- 「ページの区切りを入れる」で、コピー・保存するときに「― 1ページ ―」の区切りを入れるかを選べます
- 文字は直接書き直せます。「元に戻す」で取り出した文字に戻ります
- Wordなどで作ったPDFでよくある「⽇」（部首の文字）が「日」にならない文字化けは、自動で普通の漢字に直します
- スキャンしたPDFや写真のPDFは文字が入っていないので、「画像から読み取る（OCR）」または「文字のないページを読み取る」で画像から読み取ります。文字の種類は 日本語（横書き）/ 日本語（縦書き）/ 英語 から選びます。OCRは読みまちがいがあるので、確かめてから使ってください
- OCRのデータ（約11MB）は初めて使うときに読み込み、2回目からはオフラインでも使えます
- 開くのにパスワードが必要なPDFは使えません。PDFはどこにも送信されず、ブラウザ内で処理されます

## PDFに手書き・署名

- 「PDFを開く」またはドラッグでPDFを開き、ページの上に直接書き込みます
- 「ペン」「蛍光ペン」でなぞって書く（マウス・タッチペン・指）。色5色・太さ3段階。蛍光ペンは下の文字を隠しません
- 「消しゴム」でなぞった線やハンコを消す。元に戻す/やり直す（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>）
- 「ハンコ」: 名前を入れた丸い印鑑（4文字までOK）、「済」「確認」「提出済」（朱色）、「✓ ○ × △」と今日の日付（いまの色）。押したい場所をクリック
- 「署名」: 枠の中にサインを書くと、このブラウザに5つまで保存され、何度でも使えます
- 「選択」でハンコ・署名・線をドラッグして移動、右下の角で大きさを変更、<kbd>Delete</kbd> で削除
- 「PDFを保存」で `元の名前_書き込み済み.pdf` をダウンロード。元のページの文字はそのまま残り、書き込みはその上に重ねます
- 保護（編集制限）がかかったPDFも保存できます。その場合は元のページを画像にしてから書き込みます（文字の選択はできなくなります）。開くのにパスワードが必要なPDFは使えません
- 同梱ライブラリは pdf.js 4.10.38（表示）と pdf-lib 1.17.1（保存）
- PDF・署名・名前はどこにも送信されず、ブラウザ内だけで処理・保存されます

## PDF一括採点

- 「PDFを追加」で提出されたPDFを何人分でもまとめて選択（Ctrl+A で全部）。PDFの入ったZIP（Google ドライブでフォルダをダウンロードしたもの など）、「フォルダ」、ドラッグ＆ドロップでも追加できます
- 全員のPDFがファイル名順（出席番号の 2 と 10 も正しい順）に縦につながって表示され、ページの上にだれのPDFかが出ます。左の一覧や「▲ 前の人」「▼ 次の人」（<kbd>N</kbd> / <kbd>Shift</kbd>+<kbd>N</kbd>）で移動
- 道具は「PDFに手書き・署名」と同じペン・蛍光ペン・消しゴム・選択に加えて、
  - 「記号」: ○ × ✓ △ 花丸（いまの色）と、「済」「確認」「よくできました」「再提出」のハンコ（朱色）
  - 「点数」: クリックして数字を入力。1人に1つで、満点を入れておくと「85 / 100」の形になります。点数は一覧にも表示
  - 「文字」: コメントを入力。「選択」でダブルクリックすると書き直せます
- 色の最初は赤。元に戻す/やり直す（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>）は全員分まとめて使えます
- 「まとめて保存」で、1人ずつのPDF（`元の名前_採点済.pdf`）と `点数一覧_日付.csv`（点数を入れたとき）を1つのZIPにしてダウンロード。「フォルダに保存」なら、選んだフォルダにそのまま書き出します。一覧の「この人のPDFだけ保存」で1人分だけ保存も可能
- 書き込みのないPDFは元のまま入ります。保護（編集制限）がかかったPDFは、元のページを画像にしてから書き込みます。開くのにパスワードが必要なPDFは使えません
- ページを閉じると書き込みは消えるので、保存してから閉じてください。大人数でも、画面から離れたページは表示を解放してメモリを節約します
- 同梱ライブラリは pdf.js 4.10.38（表示）と pdf-lib 1.17.1（保存）。ZIPの読み書きは自前の小さなコード（`shared/js/zip.js` / `unzip.js`）です
- PDFはどこにも送信されず、ブラウザ内で処理されます
