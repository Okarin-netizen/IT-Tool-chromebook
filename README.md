# IT-Tool-chromebook

学校のChromebookで、インストールなし・ブラウザだけで使える便利ツール集です。
GitHub Pages で公開して使います。

## ツール一覧

| フォルダ | ツール | 内容 |
| --- | --- | --- |
| [`pdf-text/`](pdf-text/) | PDF文字入れ | PDFに日本語の文字や写真を書き込み、新しいPDFとしてダウンロード |
| [`image-pdf/`](image-pdf/) | 画像→PDF | 写真や画像を並べ替えて1つのPDFにまとめてダウンロード |
| [`calc/`](calc/) | 関数電卓・グラフ | 三角関数・対数などの計算と、関数のグラフ描画 |
| [`todo/`](todo/) | 時間割・課題チェックリスト | 時間割と課題をブラウザに保存して管理 |
| [`timer/`](timer/) | タイマー・ポモドーロ | 勉強時間を計るポモドーロ、カウントダウンタイマー、ストップウォッチ |

トップページ（`index.html`）が共通の入り口で、ここから各ツールを選べます。

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://okarin-netizen.github.io/IT-Tool-chromebook/` で開けます

一度開くとブラウザにキャッシュされ、PDF文字入れと画像→PDFはオフラインでも動きます。

## ツールの追加方法

1. ルートに新しいフォルダ（例: `timer/`）を作り、`index.html` を置く
2. ルートの `index.html` の `<ul class="tools">` に `<li>` を1つ追加する
3. この README の表に1行追加する

ビルド作業は不要です。外部ライブラリは CDN を使わずフォルダ内に同梱します（学校のネットワークで CDN がブロックされることがあるため）。

## PDF文字入れ

- PDFを開いて、文字を入れたい場所をクリックして入力
- 文字サイズ・色（黒/赤/青/緑）を変更可能、複数行OK
- 「✥」をドラッグして移動、「✕」で削除
- 「🖼 写真を追加」で写真・画像を貼り付け（ドラッグで移動、右下の角で拡大縮小）。大きな写真は自動で縮小されます
- 「💾 PDFを保存」で `元の名前_記入済み.pdf` をダウンロード
- 編集が制限された（保護付き）PDFも保存可能。この場合は元のページを画像にしてから書き込むため、元の文字は選択・検索できなくなります
- PDFはどこにも送信されず、ブラウザ内で処理されます

## 画像→PDF

- 「🖼 画像を追加」またはドラッグ＆ドロップで写真・画像を何枚でも追加（Ctrl+V でスクリーンショットの貼り付けもOK）
- 「📷 カメラで撮る」でChromebookのカメラから直接撮影して追加
- 画像をドラッグするか「◀ ▶」で並べ替え、「⟳」で90°回転、「✕」で削除、「↕ 名前順」でファイル名順に整列
- 用紙（A4 / B5 / レター / 画像に合わせる）、向き（自動 / 縦 / 横）、余白、色（カラー / 白黒）を選べます
- 「💾 PDFを保存」で1枚1ページのPDFをダウンロード。大きな写真は自動で縮小されます
- iPhoneのHEIC形式はブラウザが読めないため、JPEGで撮影・保存したものを使ってください
- 画像はどこにも送信されず、ブラウザ内で処理されます

## 関数電卓・グラフ

- 「🧮 電卓」: sin・cos・tan（と逆関数）、ln・log、√、累乗、階乗、π、e、前の答え（Ans）が使えます
- 角度は DEG（度）/ RAD（ラジアン）を切りかえ可能。`2π`・`3(1+2)` のようなかけ算記号の省略もOK
- キーボードでも入力でき、Enter で計算、Esc で消去。計算の履歴は押すと呼び出せます
- 「📈 グラフ」: `y = x^2-2x-3` のように式を入れると、最大8本まで色分けして描きます（角度はラジアン）
- ドラッグで移動、ホイールやピンチで拡大縮小、カーソルを近づけるとグラフ上の座標を表示
- 式・履歴・設定はこのブラウザに保存されます。外部ライブラリなし、オフラインでも動きます

## 時間割・課題チェックリスト

- 時間割のマスをクリックして科目を入力（4〜8時間、土曜の表示切り替えOK）。今日の曜日に色が付きます
- 課題は内容・科目・締め切りを入れて追加。締め切りが近い順に並び、過ぎたものは赤、今日・明日のものはオレンジで表示
- チェックで完了、「完了した課題を消す」でまとめて削除
- データはブラウザ（localStorage）に自動保存。「⬇ バックアップ」でファイルに保存、「⬆ 読み込み」で復元できます

## タイマー・ポモドーロ

- **🍅 ポモドーロ**: 集中25分 → 休憩5分をくり返し、4回ごとに長い休憩15分（時間と回数は「⚙ 時間の設定」で変更可能）。今日の集中回数と分数を記録
- **⏳ タイマー**: 1〜60分のボタン、または分・秒を入力してカウントダウン。テスト練習に
- **⏱ ストップウォッチ**: 0.1秒単位、ラップ記録つき
- 時間になると音（オフにも可）と、別のタブを見ているときは通知でお知らせ
- 「⛶」で全画面表示。動いている間は画面が暗くならないようにします
- ページを閉じたり再読み込みしても、続きから表示されます
- キーボード: スペース=スタート/一時停止、R=リセット、F=全画面、L=ラップ
