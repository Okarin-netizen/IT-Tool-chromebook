# 要求の一覧（Chromebook便利ツール）

IPA「AI時代の要求管理ハンドブック」の考え方で、この制作物の要求をまとめた台帳です。
2026年11月23日の点検で書き起こしたものなので、状態はすべて「候補」です。
すでに実装されているものも、内容を確かめて「承認」にするまでは「候補」のままにしています。

## 目的

- 何のため：先生と生徒が学校のChromebookで、写真・PDF・名簿などの細かい作業を、ファイルを外に出さずに片づけられるようにする
- 誰のため：パソコンが苦手な先生を含む先生たち（校務）と、授業で使う生徒
- 成功の目安：ツールごとに「何の困りごとを解くか」を1行で書き、その困りごとが解けたかで判断する（ツールごとの目的は今後足す）

## AI要求

対象：かおトリ・かおかくし・人ごとに分ける。ハンドブック表18の項目で書いています。「要決定」は岡田が決める所です。

| 項目 | 内容（案） |
|---|---|
| 利用目的 | 学校の写真・動画を公開・配布する前に顔や名札を隠す。証明写真の切り抜きを楽にする |
| 利用範囲 | 先生が校務で使う。生徒が使う場面を認めるかは要決定 |
| 禁止範囲 | 生徒を特定・追跡するための「人ごとに分ける」の利用（要決定） |
| 入力データ | 写真・動画。端末の中だけで処理し、保存・送信しない |
| 出力要件 | 隠した写真・動画。見つけた顔の一覧を出し、隠さない顔は人が選ぶ |
| 人間の関与 | 保存・公開の前に、先生が最後まで確かめる |
| 評価指標 | 隠れなかった顔の数（見逃し）と、間違えて隠した数 |
| 監視・更新 | MediaPipe などの版を上げたら、評価用の写真・動画で見逃しを比べ直す |
| 証跡 | 公開前に確かめた日と人（校内の手順として） |
| インシデント対応 | 隠し忘れが見つかったら公開を止めて差し替える |

## 書き方のきまり

- 状態は「候補 → 承認 → 実装中 → 検証済み」と進めます。やめたものは「見送り」、決めかねているものは「保留」にします。
- 要求を変えたら、変更の履歴に日付と理由を書きます。IDは使い回しません。
- 受入条件を確かめたら、結果の欄に日付と結果を書きます。
