# 目的と要求

このサイトが何のためにあるか、何を守るかをまとめた表です。新しいツールを足すか迷ったとき、直す順番を決めるときに見ます。
考え方は IPA『AI時代の要求管理ハンドブック』によります（2026年11月23日に点検）。

## 目的

| | 内容 |
| --- | --- |
| 目的 | 中学校の Chromebook で、インストールなし・通信なしで、PDF・写真・印刷・授業の小さな困りごとをすぐ片付ける |
| 使う人 | 先生（採点・印刷の準備・授業で映す・行事の写真）と生徒（提出物をPDFにする・勉強の道具）。Chromebook は1人1台 |
| ほかの関係者 | 情報担当（端末とネットワーク）、管理職（個人情報の扱い）、保護者（写真に写る子の家族）、ほかの学校の先生（MITで配布） |
| 成功の目安 | 先生が説明を読まずに1つの作業を5分以内に終えられる／生徒は授業で配ったURLだけで使える／個人情報が端末の外に出ない |
| 避けたいこと | 成績・名簿・顔写真が漏れる・残る／顔の見落とし／学校のネットワークで動かない |

成功の目安は、作成者が決めて直してください（今は案です）。

## 決まりごと（R-04 を守るため）

- ブラウザに保存する名前（localStorage のキー）は、ツールのフォルダ名で始めます（例: `class-picker-v1`、`pdf-image.format`）。「全部消す」はこの名前で見分けるので、ほかの名前にすると消えません
- 大きなもの（PDFなど）は `shared/js/kv.js`（IndexedDB）に入れます。「全部消す」で全部消えます
- 生徒の名前・成績・顔に関わるものを新しく残すときは、`about.html` の「この端末に残るもの」の表に行を足します
